# AiMINECRAFT ⛏️

Prosty klon Minecrafta w **Javie 17 + LWJGL (OpenGL)** — projekt pod IntelliJ IDEA.

- Nieskończony teren (szum Perlina) + drzewa 🌳
- Chodzenie, skakanie, sprint, **latanie** 🕊️
- Kolizje gracza ze światem
- Niszczenie i stawianie bloków (LPM/PPM), 6 bloków pod klawiszami `1`–`6`
- Prawdziwe tekstury 16×16 z `teksturki.zip` (trawa, ziemia, kamień, drewno, liście, bedrock)

**Start:** otwórz ten katalog w IntelliJ jako projekt Maven i uruchom `Main.java` (▶).
Pełna instrukcja krok po kroku → **[TUTORIAL.md](TUTORIAL.md)**.

Sterowanie w skrócie: `WASD` + mysz, `Spacja` skok, `F` latanie,
`LPM/PPM` niszcz/stawiaj, `1-6` wybór bloku, `Esc` uwolnij mysz.
