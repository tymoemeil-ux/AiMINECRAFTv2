# AiMINECRAFT 2.0 ⛏️

Klon Minecrafta w **Javie 17 + LWJGL (OpenGL)** — projekt pod IntelliJ IDEA.

- Biomy, oceany i plaże, jaskinie, rudy, 3 rodzaje drzew 🌳
- Woda + pływanie, dzień/noc z zachodami słońca 🏊
- Survival / Creative, ekwipunek, stół rzemieślniczy, 16 receptur 🎒
- Chat z komendami, panel admina (G), zapis świata, dźwięki ⌨️
- Prawdziwe tekstury 16×16 z `teksturki.zip`

**Start:** otwórz ten katalog w IntelliJ jako projekt Maven i uruchom `Main.java` (▶).
Pełna instrukcja krok po kroku → **[TUTORIAL.md](TUTORIAL.md)**.

Sterowanie w skrócie: `WASD` + mysz, `Spacja` skok, `F` latanie,
`LPM/PPM` kop/stawiaj, `E` ekwipunek, `T` chat, `G` panel admina, `Esc` pauza.
